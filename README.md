## 📌 Descripción del proyecto

GirlGaming es una aplicación web desarrollada con ASP.NET MVC que permite administrar y visualizar un catálogo de videojuegos de forma sencilla, moderna y visualmente atractiva.

La aplicación permite:

- Visualizar videojuegos registrados.
- Filtrar videojuegos por categoría.
- Agregar nuevos videojuegos al catálogo.
- Mostrar información como:
  - Nombre
  - Género
  - Plataforma
  - Año
  - Imagen de portada
